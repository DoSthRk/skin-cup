# VALORANT-CUP 首页品牌升级设计

## 目标

重做首页品牌层级，让 `VALORANT-CUP` 成为第一视觉焦点，中文标题改为
`决战皮肤之巅`，并让三个武器入口通过真实皮肤 PNG 建立更直接的主题识别。

## 品牌区

- 使用原创图形标识，不复制或描摹无畏契约官方 Logo。
- 图形方向为竞技奖杯与双向交锋结合的几何徽记，沿用网站红、黑、青配色。
- 图形标识制作成透明 PNG，适配深色背景。
- `VALORANT-CUP` 使用页面文字渲染，作为唯一一级标题，保证拼写准确和响应式清晰度。
- `决战皮肤之巅` 作为中文副标题，位于英文主标题下方。
- 保留“选择武器，开启你的皮肤锦标赛。”作为操作引导。

## 武器入口

三张入口卡继续显示武器名和皮肤数量，并在卡片右侧嵌入本地 PNG：

- 狂徒：光明哨兵狂徒
- 幻影：离子武器幻影
- 正义：奇点正义

皮肤图使用项目现有目录中的官方数据源下载并随站点发布，不依赖首页运行时远程请求。
图片不遮挡按钮文字；移动端保持完整可点击区域和可读性。

## 交互与适配

- 点击整张武器卡仍进入对应赛事，不增加额外步骤。
- 桌面端三张卡可横向展开；窄屏自动变为单列。
- 保留键盘焦点、悬停和按压反馈。
- 图片加载失败时，卡片文字和进入赛事功能仍可正常使用。

## 验证与发布

- 更新首页组件测试，覆盖英文主标题、中文副标题、三张皮肤图和武器入口。
- 执行现有完整测试、类型检查和生产构建。
- 使用真实浏览器检查桌面端与移动端首页视觉。
- 推送主分支，并更新独立服务器 release 与项目现有 Sites 版本。
