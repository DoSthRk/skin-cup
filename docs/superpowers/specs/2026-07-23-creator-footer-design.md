# 全站作者页脚设计

## 目标

在首页、赛事流程和冠军结果页最下方增加统一作者署名。默认保持紧凑，用户悬浮、键盘聚焦或手机点击后向上展开个人资料卡。

## 默认署名

- 显示 Clint 的头像。
- 显示 `MADE BY` 和作者名 `Clint`。
- 作为页面正常流中的页脚，不固定在屏幕角落，不遮挡赛事按钮。

## 展开卡片

- 桌面端鼠标进入作者区域时展开，离开时收起。
- 键盘聚焦作者区域时展开，焦点离开后收起；按 Escape 也可关闭。
- 触屏设备点击署名切换展开和收起。
- 卡片向上展开，包含：
  - 较大的 Clint 头像和作者身份；
  - GitHub 主页链接 `https://github.com/DoSthRk`；
  - 用户提供的微信二维码和“微信联系”标签。
- 不显示 VALORANT ID。

## 视觉

- 沿用网站的深色、Valorant 红和青色。
- 头像使用圆角裁切，二维码保留完整原图并放在白色底板中，确保可扫描。
- 卡片宽度限制在手机视口内；桌面端保持紧凑。
- 展开层具有边框、阴影和足够的层级，不被首页或赛事内容裁切。

## 代码边界

- 新建 `CreatorFooter` 组件，内部只负责作者资料及展开交互。
- `App` 在首页分支和赛事分支复用同一个组件。
- 两张用户图片复制到 `public/creator/`，不依赖外部图片服务。
- 现有比赛、分享图、存档和服务器配置不变。

## 验证

- 组件测试覆盖默认署名、GitHub 地址、二维码、点击展开和 Escape 关闭。
- App 测试确认首页和赛事页均包含作者署名。
- 完整测试、类型检查和构建通过。
- 真实浏览器分别验证桌面悬浮/点击和窄屏手机布局。
