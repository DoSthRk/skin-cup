# Valorant Skin Cup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a simplified-Chinese, mobile-first Skin Cup that lets a player crown a favourite Vandal, Phantom, or Sheriff skin from the complete approved pool.

**Architecture:** A Vite React TypeScript single-page application owns tournament state locally. A build-time catalog script fetches public skin metadata and applies the approved policy; a pure tournament domain module builds balanced groups, revival candidates, and knockout rounds. UI components render one phase at a time and persist versioned state in localStorage.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, Testing Library, Canvas API, static CSS.

---

## File structure

- `package.json` — scripts and development dependencies.
- `vite.config.ts`, `tsconfig.json`, `index.html` — Vite and TypeScript configuration.
- `scripts/skin-policy.mjs` — approved catalog rules and weapon tournament configurations.
- `scripts/sync-skin-catalog.mjs` — downloads upstream data and writes the generated application catalog.
- `src/domain/types.ts` — shared data and tournament types.
- `src/domain/catalog.ts` — deterministic policy filtering and catalog normalization.
- `src/domain/tournament.ts` — group seeding, phase transitions, bracket progression, and undo snapshots.
- `src/data/generated-skin-catalog.ts` — generated catalog committed for offline application startup.
- `src/lib/storage.ts` — versioned localStorage read/write helpers.
- `src/components/*.tsx` — focused screen and reusable card components.
- `src/App.tsx`, `src/main.tsx`, `src/styles.css` — application composition and visual design.
- `tests/*.test.ts` — catalog, tournament, storage, and UI tests.
- `README.md` — local start, catalog refresh, test, build, and static deployment instructions.

```ts
import { createTournament, confirmGroupPick, confirmWildcards, chooseWinner } from '../src/domain/tournament';
import type { TournamentState } from '../src/domain/types';

function finishAllGroups(state: TournamentState) {
  let current = state;
  while (current.phase === 'groups') {
    const group = current.groups[current.groupIndex];
    current = confirmGroupPick(
      current,
      group.slice(0, current.config.picksPerGroup).map((skin) => skin.id),
    );
  }
  return current;
}

it('uses every configured Vandal skin exactly once in groups', () => {
  const state = createTournament(vandalSkins, weaponConfigs.vandal, 'fixed-seed');
  expect(state.groups.flat()).toHaveLength(42);
  expect(new Set(state.groups.flat().map((skin) => skin.id)).size).toBe(42);
});

it('creates a 32-card bracket after Vandal groups and revival', () => {
  const grouped = finishAllGroups(createTournament(vandalSkins, weaponConfigs.vandal, 'fixed-seed'));
  const revived = confirmWildcards(grouped, grouped.losers.slice(0, 4).map((skin) => skin.id));
  expect(revived.bracket[0]).toHaveLength(16);
});
```
